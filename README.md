# 📊 Final Project – Sales Data Analysis and Dashboard

## 1. Introduction

This project is created using Microsoft Excel to analyze sales data and present important information in tables, charts, and a dashboard.

The main purpose of this project is to understand sales performance, compare products and categories, analyze regional sales, and identify important business trends.

## 2. Objectives

- Analyze the given sales dataset.
- Calculate total revenue and other important KPIs.
- Create summary tables using Excel formulas.
- Create PivotTables to summarize data.
- Prepare charts and visualizations.
- Design an attractive and easy-to-understand dashboard.
- Perform What-If Analysis and regression analysis.
- Understand sales trends and business performance.

## 3. Workbook Sheets

### 📋 Sheet 1: Project Instructions
This sheet contains the instructions and tasks required for the final project.

**Purpose:**
- Understand the assignment requirements.
- Follow the instructions step by step.
- Complete all required Excel tasks.

### 🗃️ Sheet 2: Raw Data
This sheet contains the original transaction records used for analysis.

**Purpose:**
- Store the original dataset.
- Review transaction dates, customer details, products, categories, quantities, and prices.
- Provide data for calculations, PivotTables, and charts.

### 📈 Sheet 3: Analysis
This sheet contains calculations and summary information based on the dataset.

**Purpose:**
- Calculate total revenue.
- Analyze product and category performance.
- Compare regional sales.
- Review monthly sales trends.
- Calculate important business indicators.

### 🧮 Sheet 4: Pivot Tables
This sheet contains summarized data used to compare different aspects of sales.

**Purpose:**
- Summarize revenue by category.
- Compare sales by region.
- Analyze product performance.
- Organize large amounts of data into meaningful summaries.

### 📊 Sheet 5: Visualizations
This sheet presents sales information through charts and graphs.

**Charts included:**
1. Revenue by Category
2. Revenue by Region
3. Units by Product
4. Monthly Revenue

**Purpose:**
- Make the data easier to understand.
- Identify high-performing categories and regions.
- Compare product sales.
- Understand changes in revenue over time.

### 🎯 Sheet 6: What-If & Regression
This sheet is used to explore possible sales outcomes and forecasting methods.

**Purpose:**
- Compare different sales scenarios.
- Use Goal Seek to find a required input for a target result.
- Explore revenue projections.
- Understand linear regression for analyzing relationships in data.

## 4. Step-by-Step Project Workflow

1. Open the Project Instructions sheet.
2. Read all instructions carefully.
3. Review the Raw Data sheet.
4. Perform the required calculations in the Analysis sheet.
5. Create or review the summary tables in the Pivot Tables sheet.
6. Prepare charts in the Visualizations sheet.
7. Perform scenario analysis in the What-If & Regression sheet.
8. Arrange the charts and KPI summaries properly on the Dashboard.
9. Check all formulas, tables, and charts.
10. Save the completed Excel workbook.
